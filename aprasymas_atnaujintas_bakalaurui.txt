================================================================================
PROJEKTO FAILŲ GIDAS
Bakalauro darbo versija
================================================================================

Šis failų gidas aprašo bakalauro darbo repozitorijos versiją.
Jis skirtas paaiškinti, kokie failai palikti projekte, kokią funkciją jie atlieka
ir kaip jie susiję su galutiniais eksperimento rezultatais.

Darbo tema:
„Lietuvos BVP išankstinis prognozavimas: tradicinių ir alternatyvių duomenų
šaltinių panaudojimas“.

Ši repozitorijos versija nėra pilna ankstesnio plataus nowcasting projekto kopija.
Joje palikti pagrindiniai failai, kurie buvo tiesiogiai arba netiesiogiai naudoti
bakalauro darbo eksperimentuose:

- duomenų eksportavimui ir paruošimui;
- pseudo-realaus laiko prognozių sudarymui;
- apkarpytų kraštų problemai spręsti;
- ElasticNet, MIDAS, MIDASML, DFM ir DFM-MF modeliams;
- TACTiS-2 užpildymo metodui;
- RMSE, MAE, RMSE pokyčio ir Diebold--Mariano testo rezultatams gauti.

Ankstesnėje projekto versijoje buvo ir kitų komponentų, tokių kaip BVAR, VAE,
bridge equations, Optuna paieška, Streamlit dashboard, FRED/ALFRED/Yahoo Finance
duomenų loaderiai ir platesnė ETL infrastruktūra. Jie nėra pagrindinė galutinės
bakalauro darbo analizės dalis, todėl šiame gide aprašomi tik aktualūs arba
repozitorijoje palikti pagalbiniai failai.

================================================================================
KAIP NAUDOTIS ŠIUO PROJEKTU
================================================================================

Tipinė darbo atkūrimo seka yra tokia:

1. Eksportuoti pasirinktus Eurostat duomenis:
   python scripts/export_selected_eurostat_nowcast_data.py

2. Eksportuoti Google Trends duomenis:
   python scripts/export_selected_google_trends_data.py --dataset-key google_trends --suffix v1
   python scripts/export_selected_google_trends_data.py --dataset-key google_trends_lt --suffix lt

3. Paruošti frequency-aware duomenis:
   python scripts/prepare_selected_frequency_aware_data.py

4. Paleisti pagrindinius pseudo-realaus laiko eksperimentus:
   python scripts/run_20260508_test_experiments_lag0_selectors_RESUME_CLEAN.py --only elasticnet
   python scripts/run_20260508_test_experiments_lag0_selectors_RESUME_CLEAN.py --only midas
   python scripts/run_20260508_test_experiments_lag0_selectors_RESUME_CLEAN.py --only dfm

5. Skaičiuoti Diebold--Mariano testus:
   python scripts/run_dm_tests.py

6. Skaičiuoti Google Trends poveikį pagal RMSE pokytį:
   python calculate_gt_rmse_reduction.py

Svarbu: kai kurie rezultatų lentelių failai buvo papildomai perskaičiuoti atskirais
pagalbiniais skriptais. Jie gali būti laikomi analizės skriptais, o ne pagrindinio
pipeline dalimi.

================================================================================
PAGRINDINIAI DUOMENŲ RINKINIAI
================================================================================

Galutiniuose eksperimento paleidimuose naudoti penki duomenų rinkiniai:

1. final_thesis_baseline_common
   Darbe vadinamas 1 rinkiniu.
   Turinys: makroekonominiai Eurostat rodikliai be Google Trends.

2. final_thesis_gt_only_v1
   Darbe vadinamas 2 rinkiniu.
   Turinys: tik angliški Google Trends raktažodžiai.

3. final_thesis_gt_only_lt
   Darbe vadinamas 3 rinkiniu.
   Turinys: tik lietuviški Google Trends raktažodžiai.

4. final_thesis_common_plus_gt_v1
   Darbe vadinamas 4 rinkiniu.
   Turinys: makroekonominiai Eurostat rodikliai ir angliški Google Trends.

5. final_thesis_common_plus_gt_lt
   Darbe vadinamas 5 rinkiniu.
   Turinys: makroekonominiai Eurostat rodikliai ir lietuviški Google Trends.

Prognozės momentai:

-2, -1, 0, +1, +2

Jie reiškia mėnesius, skaičiuojamus santykinai nuo prognozuojamo ketvirčio pabaigos.

Pagrindiniai eksperimento nustatymai:

start-date = 2019-03-31
end-date = 2026-06-30
train-start = 2000-01-01
rolling-window-quarters = 76
monthly-feature-release-lag-months = 0
quarterly-feature-release-lag-months = 0
gt-release-lag-months = 0
seed = 2234

Pastaba: požymių publikavimo vėlavimai galutiniuose eksperimentuose buvo nustatyti
lygūs nuliui. Vidinis 30 dienų BVP tikslinio kintamojo vėlavimas local_data_builder.py
faile nėra tas pats kaip požymių publikavimo vėlavimas. Pagrindiniame prognozavimo
cikle prognozuojamo ketvirčio BVP reikšmė nėra naudojama mokymo imtyje.

File: nowcasting/data/vintage_builder.py
------------------------------------
Paskirtis:
Konstruoja pseudo-realaus laiko prognozavimo pjūvius.

Vaidmuo pipeline:
Tai vienas svarbiausių viso darbo failų. Jis užtikrina, kad kiekviename
prognozės momente modelis naudotų tik tuo metu prieinamą informaciją.

Pagrindinės funkcijos:
- skaičiuoja cutoff datą pagal prognozės momentą;
- maskuoja požymius, kurie nebūtų prieinami cutoff momentu;
- taiko požymių publikavimo vėlavimus;
- neleidžia prognozuojamo ketvirčio BVP reikšmei patekti į mokymo imtį;
- formuoja rolling-window mokymo imtį;
- taiko apkarpytų kraštų užpildymo metodus;
- agreguoja mėnesinius duomenis į ketvirtinį lygį ElasticNet tipo modeliams;
- palaiko AutoARIMA cache mechanizmą.

Svarbios pastabos:
Šis failas yra pagrindinis pseudo-realaus laiko logikos šaltinis. Jis padeda
sumažinti look-ahead bias riziką.

File: nowcasting/fillers/tactis2_filler.py
------------------------------------
Paskirtis:
Įgyvendina TACTiS-2 užpildymo metodą apkarpytų kraštų problemai spręsti.

Vaidmuo pipeline:
TACTiS-2 šiame darbe naudojamas ne kaip galutinis BVP prognozavimo modelis, o kaip

Svarbios savybės:
- palaiko paprastesnę ir autorių konfigūraciją;
- leidžia nustatyti context_length, prediction_length, epochs, batch_size,
  num_samples ir kitus parametrus;
- gali naudoti GPU, jei jis prieinamas;
- išsaugo užpildytas reikšmes ir diagnostikos failus;
- nesėkmės atveju gali naudoti techninį fallback mechanizmą.

Svarbios pastabos:
Darbe TACTiS-2 interpretuojamas kaip vienas iš ElasticNet apkarpytų kraštų
užpildymo metodų kartu su LOCF, vertikaliu suderinimu ir AutoARIMA.
